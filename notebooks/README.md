# Development Notebooks

This directory contains Jupyter notebooks used for development, experimentation, and testing of audioglot features.

## Purpose

- Sandbox for experimenting with new features
- Testing different approaches to transcription and translation
- Validating API interactions with external services
- Benchmarking performance of different models and configurations

## Usage

These notebooks are for development purposes only and are excluded from version control.
Add your experimental notebooks here as you develop and test new features.

## Example Notebooks

Some examples of notebooks you might create:

- `whisper_model_comparison.ipynb` - Comparing different Whisper model sizes and performance
- `vad_tuning.ipynb` - Experimenting with voice activity detection parameters
- `translation_quality.ipynb` - Comparing DeepL vs Google Translate quality
- `dataset_creation.ipynb` - Testing different dataset preparation techniques
